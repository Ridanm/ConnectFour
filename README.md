### Connect Four 
- https://www.theodinproject.com/lessons/ruby-connect-four
- The purpose of this game is for the player to place 4 colors of the same type in four consecutive squares.
- This game can be played by two people or you can also play against a bot which I have implemented for use by a single person.
- In the development of the game I have dedicated myself to using Rspec for its implementation and understanding of said testing framework.
